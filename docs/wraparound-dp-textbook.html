0读法

本书只讲 TRF 流水线的最后一级：验证。前面的元组扫描、距离记账、统计判据，请先读主教材《串联重复的寻找》第 5、6 章。本书假设读者已经知道：候选是一个二元组 (position, d)，其中 d 是候选周期，position 是当前扫描位置。

  1. WDP 是什么？它为什么能把“模板起点未知”“拷贝有错配和插入缺失”这两件事一起解决？
  2. trfrs 怎么实现它？全矩阵版、窄带版、回溯、共识重对齐分别落在哪些函数和数据结构上？

1问题：周期没有起点

假设扫描器在位置 i = 20 发现了一个候选，提示周期 d = 7。这并不等于“从位置 14 到 20 是一个完整的重复单元”。它只说明：位置 20 和位置 13 附近有相同或相近的 7-元组。真正的重复可能：

  • 从位置 5 开始，到位置 60 结束；
  • 第一份拷贝从模板的第 3 个碱基开始；
  • 某两份拷贝之间少了一个碱基，后面的相位整体左移；
  • 两份拷贝之间多了一个碱基，后面的相位整体右移；
  • 两端各只有半份拷贝。

如果用普通比对，把“位置 14 到 20 的 7 个碱基”当成固定模板，会同时遇到三个困难。

1.1 困难一：模板的起点是任意的

模板是从序列中间截出来的。它的第 0 列不一定对应重复单元的“第一个”碱基。把模板旋转一下，比对分数可能完全不同；但重复本身没有变。程序不能预先知道该旋转多少。

1.2 困难二：插入缺失会让相位漂移

相邻拷贝之间如果有一个插入或缺失，模板列与序列行就不再保持“每走一行、列也走一列”的固定关系。比对路径会偏离对角线。漂移量随周期长度增长，但通常远小于周期本身。

1.3 困难三：起止位置未知

候选点只是重复内部的一个证据点。重复可能向左右各延伸很远，也可能在候选点附近就结束。程序需要一次比对同时决定：最佳分数、左边界、右边界、拷贝数。

WDP 的三个关键词

Wraparound 解决困难一：模板首尾相接，任意旋转都等价。
Dynamic programming 解决困难二：允许错配和插入缺失，用分数选择路径。
Local alignment 解决困难三：分数下限为 0，比对可以在任意位置开始和结束。

1.4 WDP 不是“把序列复制一遍”

“环绕”不是说把序列首尾接起来，也不是把模板字符串物理复制成两倍。它只改一件事：模板的列号对 m 取模。列 m−1 的右边是列 0，列 0 的左边是列 m−1。这样一条比对路径可以自然地从模板末尾绕回开头，继续匹配下一份拷贝。

2经典 WDP：把模板接成环

2.1 问题定义

给定文本 T[1..n] 和模板 P[0..m−1]，在 T 中找一个子串，使它和 P 的某个循环旋转最佳对齐。若模板可以重复出现，就继续沿着环走，直到比对结束。目标是最大化比对分数。

TRF 论文把 WDP 归到两篇文献：Miller 与 Myers 1989 的序列比对框架，以及 Fischetti、Landau、Schmidt、Sellers 1992 的“环状模板周期出现”算法。后者的标题直接对应这里的问题：模板没有固定起点，匹配可以在模板的任意位置开始和结束。TRF 借用这个思想，但把它改造成了局部、双向、可带化的版本；本书第 3 章会把这几层分开。

2.2 环状列

把模板看成环之后，列号只有 m 种，但每条路径可以绕任意多圈。列 c 的右邻是 (c+1) mod m，左邻是 (c−1+m) mod m。代码里到处出现的 % size、+ size 就是这两个式子。

2.4 局部 WDP 的递推式

设 S[r][c] 表示：在序列第 r 位、模板第 c 位结束的最佳局部比对分数。三条转移路径是：

路径动作分数变化
对角线序列取一个碱基，模板取一个碱基+α（相同）或 +β（不同）
上序列取一个碱基，模板不动+δ（序列多一个碱基）
左序列不动，模板前进一个+δ（模板多一个碱基）
S[r][c] = max( 0, S[r−1][(c−1+m) mod m] + sub(T[r], P[c]), S[r−1][c] + δ, S[r][(c−1+m) mod m] + δ ) 四项分别是：重新开始、对角线、上、左。取 0 是局部比对；sub(a,b) 是相似度得分，相同为 α，不同为 β。δ 是负数。

初始条件 S[0][c] = 0（对所有 c），S[r][·] 的第一列按环取左邻。答案是全表最大值。回溯从最大值所在格出发，沿着“哪个前驱加上对应分数等于当前分数”一路往回走，直到分数为 0。

为什么环状列就够了

局部比对允许在任何位置从 0 重新开始。把列号取模后，路径可以从任意模板列起步，绕一圈、两圈、任意圈。模板的旋转不再需要枚举；它变成了路径的起始列。全局比对没有这个 0 下限，才需要额外的边界初始化或两阶段扫描来枚举旋转。

2.6 经典 WDP 的边界

  • 全局形式：要求整条模板都被消耗，模板的起点和终点由同一条路径决定。为了不枚举旋转，需要在模板边界上做特殊初始化。
  • 局部形式：分数下限为 0，起止自由；环状列加 0 下限已经足够。TRF 用的是这一种。
  • 空间：完整表是 n × m。TRF 把它压到 n × 151（第 5 章），长模板再把列压到 2w+1（第 7 章）。

“WDP”不是单一算法，而是一组可以正交组合的设计选择。下面五种形态在文献和本项目里都能找到影子。前三种是通用变体；后两种是 TRF 特有的工程化改造。

“双向”和“带状”是正交的：全矩阵版也是双向的，窄带版也是双向的。“共识”是第二次调用，不是另一种递推式。把这几层拆开后，代码里的分支就清楚了。

3.1 为什么还需要“双向”

普通局部 WDP 从序列左端扫到右端，天然可以找到任意起止的比对。TRF 仍然要分成 backward 和 forward 两半，原因不是数学上必需，而是工程上更省：

  • 候选点附近一定包含重复；从候选点向左右各扫一段，比从序列开头扫到结尾更快。
  • backward 半边只需要确定重复的左边界，不要求分数精确；它可以用较窄的带。
  • forward 半边从左边界的左侧重新开始，得到干净的回溯起点和准确的分数。

代价是：backward 的分数不能直接当作最终分数。全矩阵版要靠第三遍 redo 重算；窄带版在 forward 开始时把分数清零。这是读代码时最容易误解的地方，第 6、7 章会反复强调。

4TRF 为什么需要 WDP

4.1 检测与验证分离

TRF 不直接对每个位置做比对。它先用元组扫描产生候选，再用统计判据筛掉大部分噪声，最后只对少量候选做 WDP。WDP 是流水线中最贵的一级，也是唯一能给出完整比对的一级。

1
元组扫描滚动编码，找相同 k-元组，记录距离 d。产出候选 (position, d)。
2
统计判据等待时间、区间证据和、区域竞争、最佳周期表。决定这个候选值不值得做比对。
3
第一轮 WDP模板 = 序列中以 position 结尾、长度 d 的窗口。得到分数、区间、拷贝数。
4
共识与第二轮 WDP从第一轮比对投票出共识，再用共识当模板重跑。分数和边界更准。
5
报告align_pair.score ≥ minscore 时输出。周期、拷贝数、共识、统计量都来自这条比对。

4.2 第一轮模板从哪来

fill_current_pattern(start, size, with_consensus=false) 把 sequence[start−size+1 ..= start] 复制到 current_pattern。注意这个窗口是以候选位置 start 结尾的，不是从重复的左边界开始。它可能：

  • 从第一份拷贝的中间开始；
  • 包含一个错配；
  • 包含一个多出来的碱基；
  • 跨过两份拷贝的边界。

这正是需要 WDP 的原因：模板本身不完美，但环状列和局部比对能把它“摆正”。

4.3 一次 WDP 要回答什么

问题答案从哪来
最佳分数是多少？DP 最大值，最终由 align_pair.score 报告。
重复从哪到哪？回溯得到的 sequence_index[1] 与 sequence_index[length]。
拷贝数是多少？回溯中模板列绕环的次数，加上末尾的分数份拷贝。
共识长什么样？按模板位置对第一次比对投票，得到 consensus.pattern。
实际周期是多少？报告阶段把相邻拷贝中同一模板位置的两列配对，统计它们序列位置之差的众数。

4.4 为什么要有第二轮

第一轮的模板是从序列里硬截的，带着样本自身的噪声。用共识重跑一次，相当于把“一份拷贝的观测”换成“所有拷贝的投票结果”，能降低错配和插入缺失对分数、边界的影响。第二轮结束后的 align_pair.score 才是最终报告分数。

6.1 三段式结构

wraparound_dp(start, size, consensus_present) 不是一次扫描，而是三段：

  • backward：主要用来找一个种子行 min_row，即左半部分最大分出现的最左行；它的 max_score 还会填进主 forward 的起始行，但两者都不是最终分数。
  • forward：从候选点右侧开始，把 backward 的最大分作为起始分数，记录扫描终点 wrap_end；它不直接使用 min_row，min_row 只给 redo 用。
  • redo：从种子行往前一个模板长度处重新开始，用 0 初始化，算出干净的局部比对，并记录 max_real_row / max_row / max_col。
最重要的一句话

backward 的 max_score 不是最终分数。最终分数来自 redo。读代码时不要把第一、二段的 max_score 当成报告分数。

  • 每行结束后移位对角线缓存：band_diag[j] = S[row][j+1]，band_diag[size−1] = S[row][0]。下一行要用当前行的右邻作为对角前驱，而列号是环状的。

redo 的起点是 min_row − size − 1：从 backward 找到的最左最大行再往左一个模板长度。这样做的理由是：min_row 已经落在重复内部，往左留一个模板长度就足以覆盖第一份拷贝的上下文，同时不必从序列开头重扫。

7窄带 WDP（d > 20）

7.1 为什么需要带

完整矩阵有 m 列。最大 m = 2000，序列可达百万碱基。若每个候选都填 n × m 个格子，成本不可接受。但真正有用的格子只在对角线附近：插入缺失很少，序列每走一行，模板通常也只前进一列。偏离对角线的距离就是相位漂移，它的 95% 范围远小于 m。

7.5 一行怎么填：中心跳变

中心从上一行到本行的位移记作 band_shift，已经归一化到环上的最短方向。位移有三种情况：

  • 0：中心不动；按“右移”分支处理。
  • 正：中心向更大的模板列移动；走“右移”分支。
  • 负：中心向更小的模板列移动；走“左移”分支。

由于本行的带相对上一行整体平移了 |band_shift| 个格子，本行两端会有若干格子找不到完整的前驱。代码因此把一行分成四段。以 backward、中心左移为例：

回溯从右往左走，但 fill_align_pair() 把每一步写到下标 length = 1, 2, 3, …。因此写出来的数组是反的；报告前要调用 reverse() 翻转 1..length。四个数组平行存放：

pattern_text比对后的模板字符，gap 为 -

下标 0 不用；length 是有效列数。报告阶段再用 shift_pattern_indices() 把模板下标旋转到从 0 开始，方便打印。

9共识与第二次比对

9.1 为什么第一轮的模板不够好

第一轮模板是从序列里截的一段。它可能包含：

  • 一个错配；
  • 一个多出来的碱基；
  • 一个缺失的碱基；
  • 跨越两份拷贝的边界。

用这样的模板重跑，分数会被样本噪声拉低，边界也可能偏。共识的作用是把所有拷贝的观测放在一起投票，得到更接近“祖先模板”的序列。

9.2 投票规则

get_consensus(pattern_length) 遍历第一次比对，把每个比对列按 pattern_index 分组：

  • 奇数槽位 2p+1：模板位置 p 上对齐到的序列碱基。正常一列一个。
  • 偶数槽位 2p：模板位置 p 之后插入的碱基。连续多列共享同一个 pattern_index 时，多出来的列记到这里。

然后：

  1. 对每个奇数槽位，在 A/C/G/T/— 中取多数，得到共识碱基。
  2. 对每个偶数槽位，若插入次数 / 总次数 ≥ 0.5，说明这个位置经常多出一个碱基，保留多数碱基；否则填 -。
  3. 把所有 - 去掉，压缩成 consensus.pattern；压缩后的长度是 consensus_class_length。

如果共识长度和原模板不同，process_candidate() 会把 class_length 改成共识长度：

src/scan.rs:597–602
self.class_length = distance;

if self.consensus_class_length != self.class_length {
    self.class_length = self.consensus_class_length;
}

9.4 分数与周期

最终输出里的 score 是 align_pair.score，即回溯起点格的分数，不是 DP 最大值字段。报告里的 period 也不是 class_length：report_repeat() 把相邻拷贝中同一模板位置的两列配对，统计它们序列位置之差，取众数作为 best_match_distance。有插入缺失时，实际周期和共识长度可以不同。

10评分、边界与参数

10.1 相似度矩阵

Trf::new() 建立 256×256 的 similarity_matrix：

src/state.rs:525–529

similarity_matrix[b'A' as usize * 256 + b'A' as usize] = alpha;
similarity_matrix[b'C' as usize * 256 + b'C' as usize] = alpha;
similarity_matrix[b'G' as usize * 256 + b'G' as usize] = alpha;
similarity_matrix[b'T' as usize * 256 + b'T' as usize] = alpha;

只有 A/A、C/C、G/G、T/T 得 α；其它所有组合都得 β。α = match_weight，β = −mismatch，δ = −indel。默认值是 2 / −5 / −7。

10.2 局部性与线性 gap

递推里的 max(0, …) 保证分数不会为负；每次插入缺失的代价固定为 δ，没有 affine gap（开 gap 和延伸 gap 同价）。这就是 TRF 的评分模型，比 Smith-Waterman 的仿射 gap 简单，但与它的统计模型一致。

10.3 PM / PI 不直接进入分数

PM（匹配概率）和 PI（插入缺失概率）不参与 α/β/δ。它们的作用是：

  • PM 决定元组长度与阈值表（init_criteria_tables()）。
  • PI 决定 indel_probability，进而决定带宽 range(d)。

换句话说，DP 的分数只看 α/β/δ；PM/PI 决定“哪些候选值得做 DP”和“带要留多宽”。

report_min 在 control.rs:103 被设为 0，algo.rs:984 又设了一次 0。全矩阵版的 redo 条件 max_score ≥ report_min 因此恒真；窄带版保存结果的条件也恒真。它更像一个保留的开关，而不是用户可调参数。真正决定“报不报”的是 minscore。

12不变量、风险与常见误解

12.1 不变量

  1. 环状列：所有模板列索引都在 0..m−1，任何加一/减一都取模。
  2. 局部性：每个格子的分数 ≥0；−1000 只作为屏障，不参与正常路径。
  3. 屏障只改写 0：正分路径可以穿过屏障区。
  4. 权威分数：全矩阵来自 redo，窄带来自 forward；backward 只负责定位。
  5. 回溯一致性：每一步都必须满足 S[r][c] == 前驱 + 动作分；否则代码会报 “error in trace back”。
  6. 带宽上限：2w+1 ≤ MAX_BANDWIDTH，否则致命错误。

12.2 风险

  • 带跟丢：真实比对漂出带外，分数会偏低。随机游走半径覆盖约 95%，forward 带更宽，重定心再补一层；但仍不是 100% 保证。
  • 两遍行扫描不是完整不动点：它按参考实现的顺序定义结果；换顺序、加遍数可能改变个别格子的值，从而改变输出。要逐字节一致，就照原样保留。
  • 屏障位置差一行：redo 的 start+1 与主 forward 的 start 是有意为之；改成一样会改变局部起点。
  • MAX_BANDWIDTH 是硬限制：高 PI + 长周期可能触发 fatal(-1)，不是静默降级。

12.3 常见误解

1. “backward 的最大分就是最终分数。”

不是。全矩阵版会用 redo 从 min_row−m−1 重算；窄带版在 forward 开始时把分数清零。backward 只负责找左边界/种子。

2. “窄带的 S[r][c] 里 c 就是模板列。”

不是。窄带里 c 是带内物理偏移，模板位置要由 band_centers[row] 换算。全矩阵版才是“列 = 模板位置”。

3. “WDP 会把整个序列复制一遍，形成双倍模板。”

不会。只是列号取模。模板字符串只有一份；环绕发生在索引运算里。

4. “−1000 是一个很低的真实分数。”

它是一个哨兵，表示“此路不通”。它比任何可能的真实分数都小，所以一定输给 max。

5. “report_min 就是 minscore。”

不是。当前 report_min 恒为 0；minscore 是报告前的最终门槛，作用在 align_pair.score 上。

6. “wrap_end 用来跳过已覆盖的候选。”

当前源码里 wrap_end 只写不读；真正用于跳过的是 distance_seen 中的 max_real_row。

7. “GLOBAL 回溯分支是给第二轮用的。”

不是。当前 process_candidate() 两轮都传 LOCAL；GLOBAL 分支和 max_real_col 是移植时保留的完整接口，当前调用路径不会走到。

8. “周期就是共识长度。”

不一定。共识长度是压缩后的模板长度；周期是报告阶段统计相同碱基距离得到的众数。有插入缺失时两者可以不同。

15自测题

Q1. 为什么模板列号要取模？不取模会怎样？

取模让模板首尾相接，一条路径可以从任意列开始、绕任意圈，覆盖同一模式的多次拷贝。不取模的话，模板有固定起点和终点，第一份拷贝从中间开始时就无法对齐，程序必须枚举所有旋转。

Q2. 局部 WDP 的 0 下限解决了什么？全局 WDP 为什么不能直接用？

0 下限让比对可以在任意位置重新开始和结束，因此不需要预先知道重复的左右边界。全局 WDP 要求整条模板被消耗，起止受约束；要支持任意旋转，需要额外的边界初始化或两阶段扫描。

Q3. 全矩阵版为什么要扫三遍？窄带版为什么只扫两遍？

全矩阵版的 backward 只用来找种子行，主 forward 只记录扫描终点；真正的分数和回溯起点由第三遍 redo 从种子前一个模板长度重算。窄带版的 forward 直接把分数清零，从种子行左边重新累积，所以不需要第三遍。

Q4. 窄带版的 S[r][c] 中，c 和模板列是什么关系？

c 是带内物理偏移，范围 0..2w。模板列由 band_centers[r] 换算：backward 时 pattern_col = center + w 起步向左，forward 时 pattern_col = center − w 起步向右，全部对 m 取模。

Q5. 为什么带宽用 2.3·sqrt(pI·d)，而不是固定的 6？

插入缺失造成的相位漂移是随机游走，标准差随 sqrt(d) 增长。固定带宽在长周期上会跟丢，固定的大带宽又浪费。用随机游走半径可以覆盖约 95% 的漂移，同时让带宽远小于周期。系数 2.3 是参考实现的标定值。

Q6. 重定心为什么要求连续 3 行，而不是 1 行？

一次行最大值落在对角线上可能只是随机波动。连续 3 行都沿着对角线且都是匹配，才说明真实比对已经移到带的边缘，需要把中心挪过去。

Q7. 窄带回溯里的“合法的 0”是什么？

带边界会切掉某个前驱，使 max 只能得到 0。这个 0 不是真实终点。回溯检查这个 0 能否由可用的前驱解释；能解释就继续走，避免比对被截短。

Q8. 为什么报告分数用 align_pair.score，而不是 max_score？

align_pair.score 是回溯起点格的分数，和最终输出的比对、区间、拷贝数绑定在一起。max_score 是 DP 过程的字段；全矩阵版中间两段的 max_score 还可能来自非权威的半边。用回溯起点的分数可以保证“报出的分数”和“报出的比对”一致。

Q9. 为什么 period 可能不等于 class_length？

class_length 是共识模板压缩后的长度；period 是报告阶段把相邻拷贝中同一模板位置的两列配对后，序列位置之差的众数。插入缺失会让相邻拷贝的实际间距与模板长度不同。

Q10. 如果把 SMALL_DISTANCE 调大，强制中等周期走全矩阵，输出应该变吗？

在带宽足够、没有跟丢的前提下，不应改变分数和区间；全矩阵是窄带的精确版本。可以用一段中等周期（如 30–100 bp）的测试序列对比输出，验证两者逐字节一致。若不一致，通常说明窄带跟丢或边界处理有差异。
